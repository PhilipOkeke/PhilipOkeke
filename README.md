## How I approach a project

1. Define the problem, API contract, and data model.
2. Implement small modules with clear responsibilities.
3. Test expected behavior, invalid input, and failure paths.
4. Document setup and design decisions so another developer can evaluate the work.
5. Use automated checks and iterate on issues discovered during development.
